# بهینه‌سازی معیارهای فاصله‌ی رشته با یادگیری تقویتی (String Metric RL)

[English Documentation](README.md) • [گزارش خطا و بازخورد](https://github.com/abbasi0abolfazl/string_metric_RL/issues)

یک فریم‌ورک پژوهش‌محور و مهندسی‌شده با **یادگیری تقویتی (Reinforcement Learning)** برای حل مسئله‌ی ویرایش هوشمند متن، تصحیح خطا و هم‌ترازسازی رشته‌ها در قالب **فرآیند تصمیم‌گیری مارکوف (MDP)**. عامل تقویتی یاد می‌گیرد با اجرای توالی بهینه‌ای از اعمال کاراکتری (`insert`, `delete`, `replace`, `keep`) رشته‌های نویزی یا نامنظم را با کمترین گام و بیشترین شباهت به رشته‌ی هدف تبدیل کند.

---

## 📌 فرمولاسیون ریاضی مسئله (MDP)

بر خلاف روش‌های مرسوم هم‌ترازسازی پویا یا مدل‌های حجیم زبانی، در این فریم‌ورک ویرایش متن به صورت یک چرخه‌ی تعاملی عامل و محیط مدل‌سازی شده است:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        محیط و فضای حالت (State S_t)                    │
│  - رشته‌ی فعلی و فاصله‌ی آن با رشته‌ی هدف                                │
│  - بردارهای فاصله لِوِن‌اشتاین (Levenshtein) و ژارو-وینکلر (Jaro-Winkler) │
│  - ویژگی‌های توزیع کاراکترها و موقعیت‌های نشانگر ویرایش                  │
│  - امبدینگ‌های معنایی مبتنی بر ترنسفورمرها و TF-IDF                     │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        فضای عمل عامل (Action Space A_t)                │
│  - INSERT(char, pos): درج کاراکتر در موقعیت                            │
│  - DELETE(pos): حذف کاراکتر از موقعیت                                  │
│  - REPLACE(pos, char): جایگزینی کاراکتر                                │
│  - KEEP(pos): حفظ وضعیت و رفتن به گام بعد                              │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        فرمول پاداش (Reward Formulation R_t)            │
│  R_t = Δ(Similarity) - λ · (Step Cost) + Bonus(Exact Match)            │
│  - پاداش مثبت برای کاهش فاصله تا متن هدف                              │
│  - جریمه برای گام‌های بیهوده، حلقه‌های تکراری یا تخریب متن             │
└────────────────────────────────────────────────────────────────────────┘
```

## ✨ قابلیت‌ها و اجزای فنی

### ۱. موتور تحلیل و متریک‌های تشابه متنی (`analiys.py`)
- فاصله‌های نحوی: فاصله لون‌اشتاین، نسبت تشابه لون‌اشتاین، ضریب ژارو-وینکلر.
- بازنمایی‌های معنایی: شباهت کسینوسی مبتنی بر TF-IDF و امبدینگ‌های متنی HuggingFace Transformers.
- تحلیل کاراکتری، استخراج n-gram و ماتریس آشفتگی کاراکترها.

### ۲. محیط سفارشی یادگیری تقویتی (`AdvancedArabicTextEnv` در `rl.py`)
- شبیه‌ساز گام‌به‌گام ویرایش با رابط استاندارد Gym-like.
- فضای مشاهده ترکیبی از فیچرهای برداری و معیارهای فاصله رشته‌ای.
- تعیین سقف گام مجاز، توقف زودهنگام در صورت همگرایی کامل و جریمه زمان.

### ۳. الگوریتم‌های یادگیری تقویتی پیاده‌سازی‌شده (`arabic_rl_editor/rl_agent.py`)
- **عامل DQN (Deep Q-Network):** شبکه عصبی Q در PyTorch همراه با بافر بازپخش تجربه (Experience Replay) و شبکه هدف (Target Network) برای پایداری یادگیری.
- **عامل Q-Learning جدول‌بندی‌شده:** نسخه مبتنی بر حالات دیسکریت‌شده جهت مقایسه سریع.
- **عامل گرادیان خط‌مشی (Policy Gradient / REINFORCE):** پارامتری‌سازی مستقیم توزیع احتمال روی اعمال ویرایشی.
- **خط مبنای اکتشافی (Expert Arabic Editor):** الگوریتم حریصانه مبتنی بر کمترین فاصله تئوریک جهت سنجش کارایی عامل‌ها.

### ۴. پلتفرم ارزیابی و ثبت داده‌ها (`utils.py`, `train_rl.py`, `evaluate_rl.py`)
- سیستم تله‌متری و لاگر اختصاصی `RLExperimentLogger` برای ذخیره‌سازی منحنی‌های پاداش و تاریخچه یادگیری.
- معیارهای اعتبارسنجی: نرخ همگرایی، میانگین گام‌ها تا متن هدف، و بهبود تشابه نسبی.

## 🛠️ نصب و راه‌اندازی سریع

```bash
# کلون مخزن
git clone https://github.com/abbasi0abolfazl/string_metric_RL.git
cd string_metric_RL

# ساخت محیط مجازی و نصب پیش‌نیازها
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### اجرای آزمایش کامل
```bash
python main.py
```
